Research

Monitoring, evaluation and what evidence can support.

Most of my work comes back to one question: what can we justifiably conclude about an AI agent from the evidence we actually have, and is that evidence available in time to act on? This page covers the direction I want to take, the projects so far with my part in each, and my publications.

Research direction

Three questions I want to pursue.

For prospective supervisors: each question comes from a finished project and ends with the experiment I'd run next.

1. When does a monitor buy enough time to act?

Why. Control protocols are usually scored on whether a monitor eventually flags misbehaviour. That's not the same as whether anyone could still have stopped it.

So far. In Detection Is Not Containment, detection was timely by exactly one step, and it depended on how identifiers were written. A false alarm had a measurable cost: a benign task failed.

Next. The same timing measurements across several environments with different authorization structures, with sampled monitor outputs and reported variance. Benign intervention cost reported next to prevention rate.

2. How much do audit conclusions depend on what the auditor can see?

Why. Auditors usually work from logs that were reconstructed, summarized or partly lost. Claims about an agent's objectives inherit those gaps.

So far. Ongoing work on hidden loyalties and on comparing native with reconstructed traces. No public results yet.

Next. Hold the agent fixed, degrade the evidence in controlled ways (drop tool events, summarize, reorder), and measure which audit conclusions survive.

3. When can we trust an environment a model wrote?

Why. LLMs increasingly write the simulations that agents are trained and tested in. Safety reasoning about reachability or reversibility is only as good as that environment.

So far. Generated games almost always run (134 of 135), but most don't encode the intended structure (mean structural F1 0.37). Naming a country in the prompt changed the structure produced by four of five models.

Next. Cheap structural checks that could flag a wrong environment before it's used, validated against the reference games we already have.

AI control · Monitoring

Detection Is Not Containment

Measures whether a monitor flags a prohibited action early enough for an intervention to prevent it, then replays the intervention to measure both prevention and the cost of false alarms. This project also absorbed my earlier work on intervention-aware monitoring: revoking a capability at the moment of detection.

Method
Synthetic authorization environment. Three monitor views (actions; plus reasoning; plus environment telemetry). Local qwen3:14b monitor with a frozen prompt and oracle. Threshold calibrated on benign controls only. Preregistered follow-up phases.
Result
Grounded detection was timely by one step (margin +1). Decisions held in 8 of 12 meaning-preserving identifier renamings. In a closed-loop replay, a false alarm revoked a benign agent's authority and failed its task.
Limits
One environment, single deterministic draws, fixed prompts. Says nothing about chain-of-thought faithfulness or general control performance.
My part
I built and released the monitoring experiment (Phases A–F): the environment, frozen oracle, monitor views, prefix-timing metrics, invariance diagnostics, closed-loop replay, tests and release checks. Kaustubh Gupta built the incident-forensics and checklist pipeline. I'm first author on the report.

World models · Evaluation

Do LLM-generated world models keep their structure?

If an LLM writes the environment an agent is tested in, and the environment quietly changes which states are reachable or which actions exist, any safety conclusion drawn inside it inherits that error. We tested whether LLMs can build multi-agent situations as executable partially observable stochastic games (POSGs).

Method
A 44-scenario benchmark across toy, situational, game and cultural settings. Five LLMs, three generations per model and scenario. Three evaluation lanes: mechanical validity, permutation-invariant structural matching against reference games, and qualitative coverage. Every run keeps its prompts, raw replies, generated code and validation reports.
Result
354 first-pass outputs. In the game track, 134 of 135 passed a strict mechanical check, but the mean structural F1 was 0.37 (median 0.18), with 28 of 134 exact matches. Repeated generations varied (within-pair SD 0.17). In the cultural track, naming the country in a norm-conflict prompt changed the generated structure for four of five models.
Limits
Reference structures exist only for the nine games. The link between a game's stochasticity and lower agreement (ρ = −0.68) is exploratory, from nine games.
My part
Main contributor to the shared codebase (78 of about 116 non-merge commits): experiment runners and preserved run artifacts, the graph-analysis library, the test suite, and parts of the paper source. Teammates contributed scenario data, reports, JSON generation and prompts.
Paper submitted · NeurIPS 2026 workshop PRISM AI Safety Research Fellowship, May 2026 – present. Mentored by Jobst Heitzig. Code release with tests planned shortly.
Auditing · Hidden objectives

Agent auditing under limited observability

An auditor rarely sees everything an agent did. This line of work asks which conclusions about an agent's objectives survive when traces are incomplete or reconstructed after the fact.

Agent-Trace

Evaluation infrastructure · Industry

Benchmark for long-horizon finance agent tasks

An offline-first harness for evaluating agents on multi-step accounting and due-diligence work over messy files. Task packages are generated from one canonical task file. Grading is rubric-based, with contradictions, unsafe actions and prompt-injection compliance as automatic failures. A leakage guard refuses to grade if answer files are visible to the agent.

My part
I designed and built the harness, grading engine and run pipeline at BaseThesis Labs.

Behavioural evaluation · Model welfare

The Gap Attractor Project

Do frontier language models show stable, self-directed curiosity, beyond prompted behaviour or what they say about themselves in conversation? I'm developing behavioural evaluations of autonomous information-seeking and question generation. The aim is to test whether a model's preferences persist across prompting conditions and controls, and to separate real behavioural regularities from prompt-induced ones.

Why it matters
Claims about model preferences, for AI safety or model welfare, should rest on behaviour that survives controls, not on self-reports.
Status
Started Oct 2026. No results reported yet.
Ongoing Sentient Futures, Research Fellow, Oct 2026 – present. Mentored by Julia Bossmann.

Interpretability

Prompt sensitivity and latent drift in a small causal-reasoning model

Does a model's answer flip when a causal-reasoning prompt is reworded while the causal structure stays the same, and do those flips line up with hidden-state movement? I built synthetic vignettes covering confounding, mediation and selection bias, plus variants that remove a confounder or rename terms. On Qwen2.5-0.5B-Instruct I ran prompt-stability analysis, layerwise probes and activation contrasts.

Early runs showed high answer flip rates across reframings, and the largest drift with "mechanistic" prompts. The repository is explicit that probe separability and drift are correlational and don't establish mechanism.

My part: research support for a PRISM team (mentor: Manjari Narayan). I built this experiment pipeline. Every run saves its config and a run manifest.

Representations

Latent manifold reasoning

A toy study of what happens when a smooth latent trajectory is forced through a narrow, discrete interface. It uses PCA embeddings of the scikit-learn digits data. Early versions had no baselines, and almost any perturbation looked like "collapse". Later versions compare structured routing against isotropic noise and shuffled anchors, with bootstrap intervals and permutation tests.

The result I find most interesting is a mixed one: routing damaged neighbourhood preservation while shortening one path-length measure. One metric isn't enough to judge it. None of this is evidence about real transformer hidden states.

My part: independent project. All eight versions are kept, so the method changes are visible.

Exploratory · independent

Reinforcement learning

The Matching Law in transformer-based RL agents

Does a transformer-based agent trained with Q-learning on a two-choice, MNIST-cued task allocate its choices in proportion to reward rates, as the Matching Law from behavioural psychology predicts? Reward ratios ran from 1:1 to 16:1. The report finds choice proportions close to the reward ratios, with a roughly linear log-log relationship.

My part: third of four authors, in a supporting role across methodology, software, analysis and writing (CRediT). The study was led by Yagmur Karakoc and Zahra Sarayloo.
