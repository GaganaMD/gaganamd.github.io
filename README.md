# Gagana M D — Research portfolio V3

This version renders all research, projects, writing and experience directly in `index.html`, so the content is visible even if JavaScript fails. `script.js` only powers project filters, mobile navigation, and the footer year.

Edit `index.html` to change descriptions or add verified repository/paper links. Project details are derived from the supplied LinkedIn PDF and screenshots. No unverified repository links were invented.

To publish: back up your existing GitHub Pages repository, then replace `index.html`, `styles.css`, and `script.js` and push to `main`. Review content first.
