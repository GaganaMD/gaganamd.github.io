# gaganamd.github.io

Source of https://gaganamd.github.io, the research portfolio of Gagana M D.

## How it works

- The pages are generated by a small Python script in `_build/` (needs PyYAML and Markdown:
  `py -m pip install -r _build/requirements.txt`).
  Page text lives in `_build/pages/*.html`, news in `_content/news.yml`; the shared header,
  footer and meta tags live in `_build/build.py`.
- `python _build/build.py` writes the nine pages (`index.html`, `research.html`, …) to this folder.
  Those generated files are committed, and GitHub Pages publishes them from `main`.
- `styles.css`, `script.js` and `speaking.js` are edited by hand. Pages link them with a content
  fingerprint (`styles.css?v=…`) so visitors never get new HTML with an old stylesheet.
- `cv.pdf` is built from `cv/main.tex` by GitHub Actions. See `cv/README.md`, including how to build
  the private application CV with your phone number.
- `_config.yml` lists files that are kept off the website (this README, the CV source, …).
  The repository itself is public, so never commit anything private. Private files belong in the
  gitignored `_private/` folder or outside this repository.

Full editing instructions: `_build/README.md`. A complete maintenance guide (`MAINTENANCE.md`) and a
Markdown/YAML content system are planned.

## Before every push

```bash
python _build/build.py
python _build/check.py      # must print OK: pages, fingerprints and privacy checks
```

Preview locally with `python -m http.server 8000` and open http://localhost:8000.

## Editing rules

- Only add claims a reviewer can check, or label them clearly as in progress or not public.
- Don't call a submission accepted until there's a decision.
- Never commit a phone number or other private data; `check.py` blocks phone-number-like text.
